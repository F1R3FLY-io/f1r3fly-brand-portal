# ign1t10n brand assets

ign1t10n is the installer for F1R3Gaze and the menu-bar app that runs the local shard. Its mark is the on-button.

- `*-app-icon`: the mark on the black app tile, 1024 x 1024.
- `*-horizontal-logo-*` and `*-vertical-logo-*`: the mark with the wordmark in League Spartan, built to the F1R3FLY.IO lockup rules. **Drafts, pending sign-off.**
- Colors: `color-on-dark` (for black backgrounds), `white` (for photos and dark color fields), `black` (for light backgrounds).

Each variant comes as SVG, PNG and PDF, and the `.zip` holds all three.
